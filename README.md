# Receta de estofado de cerdo 🍲

Este es mi **primer proyecto de desarrollo web**. Es una página sencilla con la receta de un estofado de cerdo, hecha únicamente con **HTML**.

## Sobre el proyecto

Quise empezar con algo simple y útil para practicar los fundamentos del lenguaje. La página presenta la receta,Ingredientes de forma no ordenada y pasos a seguir de forma ordenada y fácil de seguir.

## Qué contiene la página

- Título y descripción de la receta
- Lista de ingredientes
- Lista ordenada con los pasos de preparación
- Imagen del plato

## Tecnologías usadas

- HTML5
- Git y GitHub para el control de versiones

## Qué aprendí

- La estructura básica de un documento HTML
- Uso de listas ordenadas (`<ol>`) y no ordenadas (`<ul>`)
- Cómo insertar imágenes con `<img>`
- Flujo básico de trabajo con Git: `add`, `commit` y `push`
- Mensajes de commit con la convención Conventional Commits

## Cómo verlo

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
